# 📦 Kickbarks Moto Shop V4

A full-stack motorcycle shop management system that allows users to browse products, manage orders, and interact with a backend API.

## 🎯 Features

- User authentication (login & registration)
- Product listing and management
- Order / booking functionality
- API-based data handling
- Responsive frontend interface

---

## 🧠 Tech Stack

**Frontend**
- HTML
- CSS
- JavaScript

**Backend**
- Node.js
- Express.js
- MongoDB (Mongoose)

---

## ⚙️ Installation

```bash
git clone https://github.com/your-username/kickbarks-moto-shop.git
cd kickbarks-moto-shop
```

### Backend
```bash
cd Backend
npm install
npm run dev
```

### Frontend
Open:
```bash
Frontend/index.html
```
